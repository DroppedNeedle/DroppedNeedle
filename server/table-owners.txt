# Who owns each table in the database.
#
# Every table has one owning area, named in brackets above it. The owner
# is the area that writes the table and whose migrations change it; other
# areas may read it. A few tables are still written from more than one
# area, and those writes are moving to the owner.
#
# Writes from outside the owning area that exist today, all by library
# code inside its own transaction, when one album, artist or track row
# takes the place of another (a merge, or a scan following a retagged
# album onto its old row):
#   library_user_favorites        catalog   moved to the surviving row
#   library_user_favorite_names   catalog   moved with their favorite
#   library_play_history          media     moved to the surviving row
#   playlist_tracks               catalog   album_id set to the surviving
#                                           album (a followed retag, or a
#                                           retag joined across two scans)
#
# One more, also by library code in its own transaction: the repair that
# files plays naming no track, album or artist under the one track they
# fit. It fills those three columns of such a row and changes nothing
# else:
#   library_play_history          media     track, album and artist set
#
# Add a table here in the commit that creates it and remove it in the
# commit that drops it: the schema tests fail when this list and the
# migrated schema disagree.
